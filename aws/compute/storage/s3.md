# Amazon S3 (Simple Storage Service)

## What is S3?

- Amazon S3 is a cloud storage service provided by AWS.
- It allows you to store and retrieve files from anywhere.
- Files are stored as **objects** inside **buckets**.
- It is highly scalable, secure, and durable.

---

## Basic Concepts

### Bucket

- A bucket is a container used to store objects.
- Bucket names must be globally unique.
- A bucket can store unlimited files.

Example:

```
my-company-images-bucket
```

---

### Object

- An object is a file stored inside an S3 bucket.
- It contains:
  - File data
  - File name (key)
  - Metadata

Example:

```
profile-picture.jpg
```

Stored as:

```
my-company-images-bucket/profile-picture.jpg
```

---

## Why Use S3?

- Store images, videos, documents, and backups
- Host static websites
- Store application files
- Backup databases
- Store logs

Example:

A website stores user profile images:

```
User uploads image
        |
        ↓
Frontend
        |
        ↓
S3 Bucket
        |
        ↓
Image URL displayed
```

# S3 Storage Classes

Different storage classes are used based on access frequency.

| Storage Class | Use Case |
|---|---|
| Standard | Frequently accessed files |
| Intelligent-Tiering | Automatically moves files between tiers |
| Standard-IA | Infrequently accessed files |
| Glacier | Long-term archive |
| Glacier Deep Archive | Very long-term storage |

Example:

- Website images → S3 Standard
- Old company documents → Glacier

---

# S3 Features

## 1. High Durability

- S3 provides 99.999999999% durability.
- Data is automatically replicated across multiple servers.

---

## 2. Versioning

- Keeps multiple versions of the same file.

Example:

```
report.pdf (version 1)

report.pdf (version 2)

report.pdf (version 3)
```

Useful for recovering deleted files.

---

## 3. Lifecycle Rules

- Automatically move or delete objects after a period.

Example:

```
Upload file
     |
After 30 days
     |
Move to Glacier
     |
After 1 year
     |
Delete
```

---

## 4. Encryption

Protects data stored in S3.

Types:

- SSE-S3 (AWS managed keys)
- SSE-KMS (KMS managed keys)
- SSE-C (Customer managed keys)

---

## 5. Bucket Policy

- Controls access to a bucket.
- Uses JSON-based permissions.

Example:

Allow a website to read images from a bucket.

---

## S3 Security

Best practices:

- Keep buckets private by default
- Enable encryption
- Enable versioning
- Use IAM permissions
- Enable access logging
- Avoid public access unless required

# AWS CLI Examples

## Create Bucket

```bash
aws s3 mb s3://my-test-bucket
```

---

## Upload File

```bash
aws s3 cp file.txt s3://my-test-bucket
```

---

## List Bucket Files

```bash
aws s3 ls s3://my-test-bucket
```

---

## Download File

```bash
aws s3 cp s3://my-test-bucket/file.txt .
```

# Interview Questions

### What is S3?

- AWS object storage service used to store and retrieve files.

### What is the difference between S3 and EBS?

S3:
- Object storage
- Unlimited scalability
- Used for files and backups

EBS:
- Block storage
- Attached to EC2 instances

### Is S3 storage unlimited?

Yes, S3 can store unlimited objects.

### Is S3 regional?

Yes, buckets are created in a specific AWS Region.

### What happens when an object is deleted?

- If versioning is enabled, previous versions can be recovered.
- Without versioning, the object is permanently removed.
